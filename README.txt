SILK & STONE — WEBSITE PACKAGE
================================

This is a preview for a proposed tiling brand in Perth, WA.
The brand name is NOT cleared for Australian business name/trademark use.

WHAT IS INCLUDED
index.html — the complete mobile-friendly website
assets/ — logo, favicon and 10 real work photographs

BEFORE YOU PUBLISH FOR CUSTOMERS
1. Verify name availability and trademarks (ASIC, IP Australia).
2. Confirm permission to use work photographs from previous jobs.
3. Check applicable visa, business registration, insurance and licensing rules.
4. Add your public email and phone in the CONFIG section near the bottom of index.html.
   Change ready:false to ready:true only when the site is ready for real customers.
5. The enquiry form OPENS THE VISITOR'S EMAIL APP. It does not send in the background.

EASIEST FREE PUBLICATION FROM ANDROID — GITHUB PAGES
1. Download this ZIP, then open Files on Android and EXTRACT it.
2. In Chrome open github.com, sign in, and enable 'Desktop site' if necessary.
3. Tap + > New repository. Name it silk-and-stone-site, set Public, and create.
4. In the new repository tap 'uploading an existing file' (or Add file > Upload files).
5. Upload index.html AND the assets folder with all its files.
   The folder structure MUST be: index.html and assets/ at the repository root.
   If your phone browser cannot upload a folder, open the repository assets folder
   after creating it with a file, then upload all asset files there.
6. Commit changes. Go to Settings > Pages. Under Build and deployment,
   select 'Deploy from a branch', branch 'main', folder '/ (root)', then Save.
7. Wait a few minutes. The site address will normally be:
   https://YOUR-GITHUB-USERNAME.github.io/silk-and-stone-site/
8. Open it and test images, navigation, contact links and enquiry form.

IMPORTANT: Uploading the ZIP itself to GitHub does NOT publish the website.
You must upload its CONTENTS and keep the assets/ folder intact.
GitHub Pages hosting is free for public repositories; a custom .com.au domain costs extra.

UPDATING CONTACT DETAILS
Open index.html in the GitHub web editor. Near the end find:
const CONFIG={ready:false,businessEmail:'',businessPhone:'',whatsappNumber:'',...}
Enter your PUBLIC email and phone and set ready:true when ready. Commit changes.
Do not publish private personal details you do not want visible online.
